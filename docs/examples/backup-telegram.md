# Backups to Telegram

**1.** Settings → Telegram: enable, bot token, your chat id. Save; the bot says hello within fifteen seconds.

**2.** Settings → General → Backups: the schedule (daily is right for most), how many to keep, and **send to Telegram**. Save.

**3.** Overview → Backup → *Back up now* to test; the file arrives in the chat.

The archive holds the database, keys and every customer's credentials — the chat should be yours alone. Restore from any of them: Overview → Backup → Restore, or `w-ui` → 25.
