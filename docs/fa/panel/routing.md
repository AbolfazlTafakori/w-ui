# مسیریابی

مسیریابی تعیین می‌کند هر اتصالِ مشتری از کدام [خروجی](/fa/panel/outbounds) بیرون برود. این کار در کرنل و بر اساس آدرس انجام می‌شود: پنل همه چیزِ این صفحه — دامنه‌ها، کشورها، مشتری‌ها — را به آدرس و علامت تبدیل می‌کند، پس مسیریابی برای هر اتصال هزینه‌ای ندارد و هیچ پراکسی‌ای سر راه لازم نیست.

صفحه چهار زبانه دارد: **مسیریابی پایه**، **قوانین مسیریابی**، **بالانسرها** و **آزمایش مسیر**.

**ذخیره.** مسیریابی پایه با زدن **ذخیره** در بالای صفحه ذخیره و اعمال می‌شود؛ دکمه وقتی چیزی عوض شده فعال است. قانون‌ها و بالانسرها با ذخیره‌ی فرم خودشان ذخیره و ظرف چند ثانیه اعمال می‌شوند. ری‌استارت لازم نیست.

اگر مسیریابی روی این سرور قابل اعمال نباشد — مثلاً nftables نباشد — اعلانی در بالا می‌گوید *مسیریابی ذخیره شده ولی اعمال نمی‌شود* و دلیلش را.

## مسیریابی پایه

| تنظیم | کارش |
|-------|------|
| **خروجی پیش‌فرض** | ترافیکی که هیچ قانونی با آن جور نشود به اینجا می‌رود. انتخاب یکی اینجا آن را بالای فهرست خروجی‌ها می‌برد. بالانسر نمی‌تواند پیش‌فرض باشد: قانونی را به آن بفرستید. |
| **قطع ترافیک وقتی خروجی پیش‌فرض از کار افتاده** | پیش‌فرض روشن. وقتی پیش‌فرض یک هاپِ از کار افتاده است، ترافیکِ بی‌قانون قطع می‌شود نه اینکه از آدرس خود این سرور برود. خاموش: به **direct** برمی‌گردد. |
| **مسدودسازی پروتکل بیت‌تورنت** | پورت‌هایی را که برنامه‌های بیت‌تورنت به طور پیش‌فرض استفاده می‌کنند می‌بندد (۶۸۸۱ تا ۶۸۸۹، ۶۹۶۹، ۵۱۴۱۳، ۱۳۳۷). برنامه‌ای که از این پورت‌ها جابه‌جا شده گرفته نمی‌شود — پنل محتوای ترافیک را بررسی نمی‌کند. |
| **مسدود کردن آی‌پی‌ها** | آدرس‌ها، بازه‌ها، کشورها (`geoip:ir`) یا گروه‌های نام‌دار که مشتری‌ها نمی‌توانند به آنها برسند. |
| **مسدود کردن دامنه‌ها** | دامنه‌هایی که مشتری‌ها نمی‌توانند به آنها برسند. |
| **مسدود کردن پورت‌ها** | پورت‌ها یا بازه‌هایی — `25`، `6881-6889` — که مشتری‌ها نمی‌توانند به آنها برسند. پورت ۲۵ انتخاب رایجی است: جلوی گزارش شدن اسپم ایمیلِ مشتری‌ها به نام آدرس شما را می‌گیرد. |
| **آی‌پی‌های مستقیم** | آدرس‌ها، بازه‌ها، کشورها یا گروه‌های نام‌دار که همیشه، هر چه پیش‌فرض باشد، از آدرس خود این سرور می‌روند. |
| **دامنه‌های مستقیم** | دامنه‌هایی که همیشه مستقیم می‌روند. |
| **IPv4 مسیریابی** | دامنه‌هایی که فقط روی IPv4 پیدا و مستقیم فرستاده می‌شوند — برای سرویس‌هایی که روی IPv6 درست کار نمی‌کنند. |

**هر مورد فهرست می‌تواند این باشد:**

- یک آدرس (`203.0.113.7`) یا یک بازه (`10.0.0.0/8`، `fc00::/7`)؛
- یک کشور، `geoip:` و کد دوحرفی‌اش (`geoip:ir`، `geoip:cn`). بازه‌های کشور از فهرست‌های منتشرشده‌ی ثبت‌کننده‌های منطقه‌ای گرفته، روی دیسک نگه داشته و هر هفته تازه می‌شوند؛
- یک گروه نام‌دار: `private`، `loopback`، `link-local`، `cgnat`، `multicast`، `bogon`.

**دامنه‌ها** را پنل پیدا می‌کند و با آدرس‌هایی که به آنها می‌رسند تطبیق می‌دهد، هر ۱۵ دقیقه تازه؛ زیر فهرست‌ها پنل می‌گوید چند نام به چند آدرس رسیده. زیردامنه با آدرس‌های خودش تطبیق داده می‌شود نه با نامش: `example.com` را ببندید، `www.example.com` فقط وقتی گرفته می‌شود که به همان آدرس‌ها برسد. هر نامی را که منظورتان است بنویسید.

## قوانین مسیریابی

قانون‌ها از بالا به پایین بررسی می‌شوند؛ **اولین قانونِ جور تصمیم می‌گیرد**. ترافیکی که با هیچ قانونی جور نشود به خروجی پیش‌فرض می‌رود.

| ستون | چه نشان می‌دهد |
|------|----------------|
| **#** | جایگاه؛ دستگیره‌ی ☰ را بکشید تا ترتیب عوض شود. |
| **عملیات** | ✎ ویرایش؛ ⋮ منو را باز می‌کند: ویرایش، بالا، پایین، حذف. |
| **فعال** | کلید روشن/خاموش؛ قانونِ خاموش می‌ماند ولی نادیده گرفته می‌شود. |
| **مبدا** | مشتری‌ها، گروه‌ها، آدرس‌ها و پورت‌های مبدأ که قانون با آنها جور است. |
| **توضیحات** | یادداشت قانون. |
| **شبکه** | TCP، UDP، ICMP، یا هر کدام. |
| **مقصد** | آدرس‌ها، کشورها، دامنه‌ها و پورت‌هایی که قانون با آنها جور است. |
| **اینترفیس‌ها** | اینترفیس‌هایی که قانون رویشان اعمال می‌شود. |
| **خروجی‌ها** / **بالانسرها** | ترافیکِ جور به کجا می‌رود. |

**بیشتر** شامل **ورود قوانین** و **خروج قوانین** (JSON) است، برای جابه‌جا کردن قانون‌ها بین پنل‌ها. روی موبایل هر قانون یک کارت است: اینترفیس‌ها ← خروجی، با شرط‌هایش به شکل برچسب.

حذف یک قانون، آنچه را که با آن جور بود به قانون‌های پایین‌تر می‌فرستد.

### فرم قانون

هر فیلد قانون را محدودتر می‌کند؛ فیلد خالی با همه چیز جور است. فهرست‌ها با کاما جدا می‌شوند.

| فیلد | جور است با |
|------|-----------|
| **آی‌پی‌های مبدا** | آدرس مشتری داخل تونل، بازه‌ها یا گروه‌های نام‌دار. |
| **پورت مبدا** | `53,443,1000-2000`. |
| **شبکه** | TCP، UDP، ICMP، یا هر کدام. |
| **IP** | آدرس‌ها، بازه‌ها، کشورهای `geoip:`، گروه‌های نام‌دارِ مقصد — `0.0.0.0/8, fc00::/7, geoip:ir`. |
| **دامنه** | دامنه‌های مقصد، با آدرس‌هایی که به آنها می‌رسند. |
| **کاربر** | همین مشتری‌ها، به هر جا که بروند. |
| **گروه** | همه‌ی اعضای این گروه‌ها. |
| **پورت** | پورت‌ها و بازه‌های مقصد. |
| **اینترفیس‌ها** | ترافیکی که از این اینترفیس‌ها می‌آید. |
| **تگ خروجی** / **بالانسر** | ترافیکِ جور به کجا برود: یک خروجی یا یک بالانسر. خروجی یا بالانسرِ خاموش قابل انتخاب نیست. |
| **یادداشت** | قانون برای چیست، برای کسی که بعداً می‌خواند. |
| **فعال** | خاموش یعنی قانون بماند و نادیده گرفته شود. |

قانونی که به خروجی یا بالانسرِ خاموش یا حذف‌شده اشاره کند نادیده گرفته می‌شود — ترافیکش به قانون بعدی می‌رود — نه اینکه دور ریخته شود.

## بالانسرها

بالانسر یک برچسب روی چند خروجی است؛ قانونی را به آن بفرستید تا ترافیک بینشان پخش شود.

| ستون / فیلد | یعنی |
|-------------|------|
| **برچسب** | نامی که قانون‌ها به آن اشاره می‌کنند. |
| **استراتژی** | **random**: هر اتصال به یکی از اعضا می‌رود که با هش اتصال انتخاب می‌شود، پس بار یکنواخت پخش می‌شود و هر اتصال روی همان خروجی‌ای که شروع کرده می‌ماند؛ اعضای از کار افتاده کنار گذاشته می‌شوند. **leastPing**: هر اتصال به عضوی می‌رود که در آخرین بررسی سریع‌تر جواب داده؛ تا وقتی بالانسر leastPing وجود دارد، اعضایش دقیقه‌ای یک بار بررسی می‌شوند. |
| **خروجی‌ها** | اعضا — دست‌کم یکی. |
| **یادداشت**، **فعال** | مثل قانون‌ها. |

از طریق API یک بالانسر می‌تواند یک خروجی **fallback** هم داشته باشد که وقتی همه‌ی اعضا از کار افتاده‌اند استفاده شود، و با `POST /api/balancers/{id}/override` روی یکی از اعضا ثابت شود. بالانسری که قانون‌ها به آن اشاره می‌کنند تا آنها عوض نشوند حذف نمی‌شود.

## آزمایش مسیر

از مسیریابی می‌پرسد یک اتصال از کدام خروجی می‌رود، بی‌آنکه چیزی فرستاده شود. **دامنه یا IP** را بدهید، و در صورت تمایل **پورت**، **شبکه** و **اینترفیس**ی که از آن می‌آید، بعد **آزمایش مسیر**. جواب خروجی را نام می‌برد — و اگر از بالانسر گذشته، بالانسر را — و **آن قانون را نشانم بده** به قانونی که تصمیم گرفته می‌پرد. اگر هیچ قانونی جور نشده باشد همین را می‌گوید و خروجی پیش‌فرض را نام می‌برد.
