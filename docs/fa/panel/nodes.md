# نودها

پنل‌های W-UI دیگر، از همین‌جا با همان API که خودِ این پنل سرو می‌کند پاییده می‌شوند — نه با یک agent جدا. روی پنل دور یک توکن صادر کن (نودها → توکن‌ها)، این‌جا با آدرس اضافه‌اش کن، و این پنل هر سی ثانیه می‌پرسد: نسخه، uptime، بار، مشتری‌ها، اینکه محدودیت‌هایش اعمال می‌شود یا نه.

نودی که در دسترس نیست می‌گوید **کدام نوع** در دسترس نیست: رد شد، جواب نداد، اعتبار غلط، یا چیزی جواب داد که پنل نیست.

توکن‌ها ۲۵۶ بیت تصادفی‌اند، یک بار نشان داده می‌شوند و فقط هش‌شان ذخیره می‌شود. `wui token issue --name NAME` از شل یکی می‌سازد.
