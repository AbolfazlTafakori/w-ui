# تنظیمات

پنج تب، به ترتیب کلاسیک. هر تغییر با دکمهٔ بالا ذخیره می‌شود؛ آن‌هایی که به جای گوش دادن پنل مربوط‌اند در ریستارت بعدی اعمال می‌شوند و صفحه همین را می‌گوید.

## General

| تنظیم | |
|-------|--|
| Panel listen / port / URL path | پنل کجا جواب می‌دهد — تغییر پورت یا مسیر در ریستارت بعدی پنل را جابه‌جا می‌کند؛ آدرس جدید را قبل از ریستارت یادداشت کن |
| Panel domain، certificate، key | پنل با چه چیزی TLS سرو می‌کند؛ نصاب این‌ها را پر می‌کند |
| Session length | یک ورود چقدر می‌ماند |
| Page size | ردیف در هر صفحهٔ جدول‌ها |
| Time zone، language | برای تاریخ‌ها و رابط |
| پیش‌فرض مشتری جدید | سهمیه، روز، سقف دستگاه، چرخهٔ بازنشانی |
| Backups | زمان‌بندی، چند تا نگه داشته شود (فرستادن به تلگرام در تلگرام → بکاپ است) |
| Trusted proxies | CIDRهایی که اجازه دارند `X-Forwarded-*` بگذارند |
| Collection interval، online window | هر چند وقت مصرف خوانده شود، چقدر از handshake بگذرد هنوز آنلاین حساب شود |

## Security

نام کاربری و رمز، **ورود دومرحله‌ای** (TOTP — با هر authenticator اسکن کن، یک کد تأیید کن، کلید بازیابی را نگه دار)، اعلان ورود به تلگرام، و هشدارهای امنیتی‌ای که پنل می‌دهد (HTTP ساده، مسیر پیش‌فرض، نشست خیلی طولانی). هشدارهای حساب — ورود دومرحله‌ای خاموش، نام کاربری هنوز `admin`، رمز تولیدشدهٔ نصب هرگز عوض نشده — فقط دربارهٔ حساب مالک‌اند و هرکدام یک‌بار گفته می‌شوند؛ مدیرهای پنل بدون ورود دومرحله‌ای در یک خط با نام آمده‌اند، و برای نماینده‌ها هشداری نیست چون روشن کردن ورود دومرحله‌ای با خودشان است. *پنل از هر آدرسی در دسترس است* یعنی روی همهٔ کارت‌های شبکه (`0.0.0.0`) گوش می‌دهد، همان چیزی که نصب‌کننده تنظیم می‌کند؛ فقط وقتی مهم است که پنل پشت پراکسی یا تونل باشد و باید روی `127.0.0.1` بسته شود.

## Telegram

فعال کردن ربات، توکن از @BotFather، شناسهٔ چت مدیر(ها)، زبان ربات، و اینکه کدام رویدادها اعلان بدهند: مشتری در حال اتمام، انقضا، اشتراک‌گذاری، بک‌آپ، ورود، گزارش روزانه؛ و در تب خودش، [بک‌آپ خودکار](/fa/panel/telegram#بک‌آپ-خودکار) به چت. ربات تعاملی صفحهٔ خودش را دارد: [ربات تلگرام](/fa/panel/telegram).

## Email

میزبان SMTP، پورت، رمزنگاری، فرستنده، و همان اعلان‌ها با ایمیل برای مدیری که تلگرام ندارد.

## Subscription

فعال کردن سرویس، آدرس گوش دادن، پورت و سرتیفیکیت (لیسنر جدا یا همان پنل)، دامنه و مسیر عمومی، URI پشت reverse proxy، اینکه سابسکریپشن متنی base64 باشد یا نه، فاصلهٔ به‌روزرسانی که به کلاینت گفته می‌شود، عنوان پروفایل، لینک پشتیبانی و پروفایل، یک اعلان، و **تمپلیت** — شش ظاهر برای صفحهٔ مشتری با لینک پیش‌نمایش یک‌بارمصرف. [صفحهٔ سابسکریپشن](/fa/panel/subscription).
