# صفحهٔ سابسکریپشن

صفحه‌ای که مشتری با باز کردن لینک سابسکریپشنش در مرورگر می‌بیند. سمت سرور رندر می‌شود، پس بدون جاوااسکریپت کار می‌کند و روی اتصال بد سریع بالا می‌آید.

## روی آن چیست

- چقدر از پلن مصرف شده، چقدر مانده، کِی تمام می‌شود، آخرین بار کِی آنلاین بوده؛
- برای هر دستگاه **به ازای هر هاست** یک بلوک — متن کانفیگ، دکمهٔ کپی، دانلود، و QR که وسط صفحه باز می‌شود؛
- خودِ لینک سابسکریپشن به شکل QR، برای اپ‌هایی که سابسکریپشن می‌فهمند؛
- سوییچ زبان (فارسی / انگلیسی) و سوییچ تم؛
- لینک پشتیبانی، اعلان و عنوان پروفایل از تنظیمات → سابسکریپشن.

## تمپلیت‌ها

تنظیمات → سابسکریپشن → **Template** یکی از بیست‌ویک ظاهر را انتخاب می‌کند. **Preview** یک صفحهٔ نمونه با تمپلیت انتخابی را از لینک یک‌بارمصرف باز می‌کند تا قبل از مشتری‌ها ببینی.

| تمپلیت | ظاهر |
| --- | --- |
| `classic` | چیدمان کلاسیک پنل |
| `aurora` | نور قرمز، آبی و فیروزه‌ای روی سرمه‌ای تیره |
| `waves` | موج‌های آرام گرادیانی زیر کارت شیشه‌ای |
| `network` | بوم متحرکی از نقاط به‌هم‌وصل |
| `minimal` | سفید، تخت، بدون تزئین |
| `midnight` | سیاه خالص با درخشش قرمز |
| `ember` | زغالی با آتشی گرم که از پایین می‌درخشد |
| `ocean` | آب عمیق، سطح فیروزه‌ای آرام، کارت شیشه‌ای |
| `forest` | خزهٔ تیره با نور زمردی از میان برگ‌ها |
| `sunset` | بنفش تا کهربایی در آسمان، خورشیدی روی افق |
| `neon` | سیاه با لبه‌های سرخابی و فیروزه‌ای درخشان |
| `glass` | سفید مات روی محوی رنگی (روشن) |
| `paper` | کرم گرم، تیتر سریف، خط‌کشی (روشن) |
| `terminal` | فسفر سبز روی سیاه، خطوط اسکن، پرامپت |
| `carbon` | بافت کربن زیر فولاد براش‌خورده |
| `royal` | سرمه‌ای و طلایی، لبهٔ زراندود |
| `sakura` | سفید و صورتی شکوفه، گلبرگ‌های در حال ریزش (روشن) |
| `frost` | آبی یخی و سفید (روشن) |
| `graphite` | سطوح خاکستری تخت، یک آبی، گوشه‌های گرد بزرگ |
| `mesh` | شبکهٔ رنگارنگ آرام پشت شیشهٔ تیره |
| `retro` | سینث‌ویو: خورشید راه‌راه و شبکه‌ای تا افق |

صفحه تا وقتی باز است هر چند ثانیه خودش را تازه می‌کند: مصرف، باقی‌مانده، نوار و حلقه‌ها، دانلود/آپلود، آخرین اتصال، و نقطهٔ بالای صفحه — **Online** وقتی دستگاهی handshake تازه دارد، **Idle** وقتی پلن فعال است ولی چیزی وصل نیست، **Off** وقتی پلن فعال نیست.

همهٔ ظاهرها همان محتوا و همان کنترل‌ها را دارند — دکمهٔ تم، زبان، دانلود و کپی — فقط لباس عوض می‌شود.

## لینک

`https://host:port/sub/TOKEN`. توکن برای هر مشتری جداست و از ردیف مشتری قابل چرخاندن است؛ لینک قدیمی فوراً از کار می‌افتد. وقتی سرویس سابسکریپشن روی پورت جداست، لینک همان پورت و scheme را دارد.

## همیشه به‌روز

برای لینک چیزی ذخیره نمی‌شود: هر بار که گرفته می‌شود، کانفیگ‌ها همان لحظه از رکوردها ساخته می‌شوند. هر چه در پنل عوض شود — endpoint یا پورت، DNS، هاستی که اضافه شده، دستگاهی که تغییر نام داده، نام کاربری یا رمز OpenVPN، مشتری‌ای که به سرور دیگری رفته — در دریافت بعدی هست، و پاسخ با `Cache-Control: no-store` می‌رود تا هیچ واسطه‌ای نسخهٔ قدیمی نگه ندارد. صفحهٔ مشتری تا وقتی باز است خودش را به‌روز نگه می‌دارد: یک stream به پنل باز نگه می‌دارد و همان لحظه که چیزی در پنل عوض شود — از API، یا با تمام شدن/شروع شدن پلن توسط reconciler — پنل در آن stream می‌نویسد و صفحه ارقامش و اثرانگشت فایل‌هایی که از آن ساخته شده را می‌پرسد؛ همین که اثرانگشت فرق کند خودش را دوباره بار می‌کند. (هر سه ثانیه هم خودش می‌پرسد، برای شبکه‌ای که stream را باز نگه نمی‌دارد.) پس — تغییر نام دستگاه، جابه‌جایی آدرس، اضافه شدن سرور یا تغییر نام کاربری ظرف چند ثانیه جلوی چشم مشتری است، بدون هیچ لمسی. مصرف و نقطهٔ آنلاین بدون بارگذاری مجدد حرکت می‌کنند؛ اپ با فاصله‌ای که به آن گفته می‌شود دوباره می‌گیرد (`Profile-Update-Interval`، پیش‌فرض **۱ ساعت**، در Settings → Subscription)، پس هر تغییری ظرف یک ساعت به همهٔ اپ‌ها می‌رسد بی‌آنکه فایل جدیدی به کسی داده شود.

## فرمت‌ها

همان توکن به اپ‌ها هم سرویس می‌دهد: `?format=conf` برای فایل وایرگارد، `base64`، `zip` برای همهٔ دستگاه‌ها یک‌جا، و دانلود به ازای دستگاه و هاست که صفحه به آن لینک می‌دهد.
