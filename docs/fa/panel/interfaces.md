# اینترفیس‌ها

همان **inbounds** پنل‌های دیگر: تانل‌هایی که این سرور ارائه می‌دهد. هر اینترفیس یک زیرشبکه روی یک پورت با یک پروتکل است.

## کارت خلاصه

مجموع ارسال / دریافت، مجموع مصرف، و تعداد اینترفیس‌ها.

## نوار ابزار

**Add Inbound**، **General Actions** (وارد کردن از فایل، خروجی گرفتن لینک همهٔ مشتری‌ها، بازنشانی همهٔ ترافیک)، و جست‌وجویی که نام، پورت یا پروتکل را می‌گیرد. با ردیف‌های انتخاب‌شده: تعداد، و **Delete**.

## جدول

| ستون | |
|------|--|
| ID | قابل مرتب‌سازی |
| Menu | ویرایش، و منوی ردیف: اطلاعات، QR همهٔ مشتری‌ها، بازنشانی ترافیک، کپی، ریستارت، حذف |
| Enabled | یک سوییچ؛ خاموش یعنی همهٔ peerها از کرنل حذف می‌شوند بدون اینکه چیزی پاک شود |
| Remark | نام اینترفیس |
| Node | کدام سرور آن را حمل می‌کند، وقتی نود وصل باشد |
| Port | پورت گوش دادن |
| Protocol | `wireguard` / `openvpn`، ترنسپورت، و **AmneziaWG** وقتی مبهم‌شده باشد |
| Clients | کل، فعال، غیرفعال، تمام‌شده، آنلاین |
| Traffic | مصرف / سقف — فقط چیزی که از *همین* تانل رد شده، از شمارندهٔ خود فایل‌های آن. مشتری‌ای که هم روی WireGuard است هم OpenVPN یک حجم را خرج می‌کند، اما هر تانل فقط بابت بایت‌های خودش شمرده می‌شود؛ روی پنل و نودها یکسان |
| Speed | نرخ زنده |
| Duration | انقضا، اگر تنظیم شده باشد |

روی گوشی جدول به لیست کارت تبدیل می‌شود؛ روی ⓘ بزن تا اعداد را ببینی.

## فرم

**Basic:** نام، پروتکل، حالت (standard یا Amnezia)، زیرشبکه، پورت، endpoint host، DNS برای کلاینت‌ها، MTU، NAT interface.

**AmneziaWG** پارامترهای ابهام (Jc، Jmin، Jmax، S1–S4، H1–H4) را اضافه می‌کند؛ برایت تولید می‌شوند، برای کلاینتی که مقادیر خاص می‌خواهد قابل ویرایش‌اند.

**OpenVPN** ترنسپورت (UDP یا TCP)، cipher، و اینکه redirect-gateway push شود یا نه را اضافه می‌کند.

همه‌چیز یک اینترفیس بعد از بالا آمدن قابل ویرایش است. Endpoint، DNS، MTU و اینترفیس خروجی سر جا اعمال می‌شوند و کسی را قطع نمی‌کنند. نام، پورت، زیرشبکه و حالت تانل را پایین می‌آورند و به‌عنوان تانل جدید بالا می‌آورند، و هر مشتری روی آن کانفیگ جدید لازم دارد (لینک سابسکریپشن همان لحظه کانفیگ جدید را می‌دهد)؛ زیرشبکهٔ جدید به هر دستگاه آدرس تازه هم می‌دهد. پنل زیرشبکه‌ای که با تانل دیگری روی همان سرور هم‌پوشانی دارد و نامی که نام دستگاه معتبر نیست (تا ۱۵ حرف، رقم، `-` یا `_`) را رد می‌کند.
