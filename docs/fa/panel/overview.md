# نمای کلی

اولین صفحه بعد از ورود: بار سرور، وضعیت پنل، و آنچه این سرور حمل می‌کند. هر سه ثانیه از یک درخواست تازه می‌شود، پس همهٔ اعداد مال یک لحظه‌اند.

## نوار اکشن

چیدمان نوار مثل پنل کلاسیک است: در ابتدا وضعیت و نسخه و کنارشان برچسب به‌روزرسانی؛ در انتها دکمه‌ها.

| دکمه | چه می‌کند |
|------|-----------|
| **● تونل‌ها · 3 / 3  v2.3.1** | چند اینترفیس بالاست از چندتای فعال (نقطه وقتی یکی پایین باشد قرمز است) و نسخهٔ این پنل؛ نسخه پنجرهٔ به‌روزرسانی را باز می‌کند |
| **به‌روزرسانی v2.3.2** | فقط وقتی نسخهٔ تازه‌تری منتشر شده: پنجرهٔ به‌روزرسانی را با یادداشت‌های انتشار و دکمهٔ **نصب و راه‌اندازی دوباره** باز می‌کند. خودِ پنل نسخه را دانلود می‌کند — یک نوار نشان می‌دهد چقدر رسیده — با کلید امضای داخل خودش بررسی می‌کند، جایگزین می‌کند و دوباره بالا می‌آید؛ وقتی پنل با نسخهٔ جدید برگشت، صفحه خودش بارگذاری می‌شود. مشتری‌ها وصل می‌مانند. بستن پنجره یا بارگذاری دوبارهٔ صفحه نصب را متوقف نمی‌کند: تا تمام شود برچسب *در حال به‌روزرسانی…* را نشان می‌دهد. فهرست انتشارها حداکثر هر نیم ساعت یک‌بار بررسی می‌شود؛ باز کردن پنجره دوباره بررسی می‌کند |
| **Restart** | همهٔ تانل‌ها دوباره از پیکربندی ذخیره‌شده (همان «restart core» کلاسیک)؛ پنل بالا می‌ماند |
| **Stop** | سرویس پنل — تانل‌ها روشن می‌مانند، محدودیت‌ها دیگر اعمال نمی‌شوند |
| **History** | CPU، حافظه، ترافیک و اتصال‌ها در روز، هفته یا ماه گذشته |
| **Logs** | لاگ پنل، با فیلتر سطح و منبع، زنده |
| **بکاپ و بازگردانی** | دو خط، مثل پنل کلاسیک. **دانلود بکاپ** با یک کلیک یک بکاپ تازه از همه‌چیز می‌گیرد و روی دستگاه شما ذخیره می‌کند. **انتخاب فایل** بکاپی را برای بازگردانی انتخاب می‌کند؛ پنجره نام و حجمش، اتفاقی که می‌افتد و گزینهٔ *آدرس‌های همین سرور حفظ شود* را نشان می‌دهد، و تا **بازگردانی** را نزنید چیزی تغییر نمی‌کند. پیشرفت آپلود نمایش داده می‌شود، وضعیت فعلی اول ذخیره می‌شود و وقتی پنل با داده‌های بازگردانده برگشت، صفحه خودش بارگذاری می‌شود. بکاپ‌های قدیمی‌تر زیر *همه‌ی بکاپ‌ها* هستند |
| **System** | این باینری چیست، کرنل چه چیزی را پشتیبانی می‌کند، آیا اعمال محدودیت دقیق است |
| **Settings** | صفحه‌های تنظیمات |

## لاگ

**Logs** لاگ پنل را باز می‌کند: خط‌هایی که همین پروسه نوشته (چند هزار خط آخر، در حافظه) یا journal همان پنل روی دیسک که بعد از ریستارت هم می‌ماند. فیلتر سطح، جست‌وجوی کلمه، دنبال کردن زنده.

چه چیزی در آن هست، هر کدام یک خط:

| خط | فیلدها | کِی |
|------|--------|------|
| `action` / `action refused` / `action failed` | `action` (متد و مسیر)، `by` (مدیر، یا `token`)، `ip`، `status`، `took`، و برای رد شدن `reason` | هر تغییری که از API انجام شود — ساخت، ویرایش، حذف، تنظیمات، ریستارت |
| `client created` / `client updated` / `client deleted` | `name`، `id`؛ برای ویرایش `changed` نام ستون‌ها را می‌گوید (`quota_bytes, expires_at`) | خودِ تغییر، کنار action‌ی که آن را خواسته |
| `device connected` / `device disconnected` | `device` به شکل `مشتری / دستگاه`، `from` (آدرس عمومی)، `after` (چقدر وصل بود) | شروع ترافیک یک اعتبار، و توقفش به مدت ۷۵ ثانیه |
| `connection limit reached; device held off` / `device held off by the panel` | `client`، `device`، `on` (این‌جا یا نود)، `limit`، `until` | پلنی که از سقف اتصال هم‌زمان گذشته |
| `clients cut off for reaching their allowance` / `clients expired` | `count`، `clients` (نام‌ها) | جاروی reconciler، هر دو ثانیه |
| `admin signed in` / `failed sign-in` / `failed second factor` | `username`، `ip`، `lockout` | صفحهٔ ورود |
| `interface created` / `updated` / `deleted` / `restarted`، `driver state changed` | `name`، `port`، `added`، `removed` | تانل‌ها و peerهایشان |
| `node …` | `node`، `error` | دور نودها، فقط وقتی وضعیت نود عوض شود |

خواندن‌ها لاگ نمی‌شوند: باز کردن یک لیست رویداد نیست. ترافیک بین پنل و نودهایش هم همین‌طور.

## نوار آمار

آنلاین الان، در حال اتمام، حجم تمام‌شده، منقضی، فعال، و تعداد مشتری‌ها — هر کدام لینکی به صفحهٔ مشتری‌ها با همان فیلتر.

## علائم حیاتی

CPU، RAM، swap و دیسک با sparkline؛ throughput همهٔ اینترفیس‌ها با peak ساعت گذشته؛ اتصال‌های باز به تفکیک پروتکل. زیرشان uptime پنل و سرور، حافظه و taskهای خود پنل، و آدرس‌های عمومی سرور — پیش‌فرض پشت چشم پنهان، برای اسکرین‌شات.

## Enforcement

خطی که از نظر تجاری مهم است. **Exact (kernel quota)** یعنی محدودیت حجم با quota object در nftables اعمال می‌شود و اضافه‌مصرف یک بسته است. **Reduced** یعنی این کرنل `nft_quota` ندارد، محدودیت در تیک بعدی اعمال می‌شود و مشتری سریع اضافه می‌رود — [اعمال محدودیت چطور کار می‌کند](/fa/reference/how-it-works).
