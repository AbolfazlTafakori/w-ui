# خروجی‌ها

ترافیک مشتری‌ها از کجا خارج شود. دو تای داخلی، **direct** (آدرس خودِ این سرور) و **blocked** (دور ریخته می‌شود)، و هر تعداد hop که خودت اضافه کنی — یک peer وایرگارد، سرور دیگر، پروکسی SOCKS یا HTTP.

## قانونی که مهم است

**خروجیِ بالای لیست، پیش‌فرض است.** یک hop سالم را آن‌جا بگذار و همهٔ ترافیک مشتری‌ها از آن خارج می‌شود: آدرس خروجی هر مشتری، آدرس آن hop می‌شود — همان کاری که یک مدیر در کشور فیلترشده می‌کند تا ترافیک را از سرور تمیز عبور دهد. با منوی ردیف جابه‌جا کن (به بالا، بالا، پایین).

## Fail-closed

وقتی خروجی پیش‌فرض پایین است، ترافیک مشتری‌ها **دور ریخته می‌شود** نه اینکه بی‌سروصدا از آدرس خودِ سرور بیرون برود — آدرسی که خروجی برای پنهان کردن آن وجود دارد. مسیریابی → Basic → «Block traffic while the default outbound is down» خاموشش می‌کند.

## جدول

`#`، تگ، آدرس، egress (آدرسی که دنیا می‌بیند، پشت چشم پنهان)، کشور، ترافیک، تأخیر، و **Check** — probe از طریق TCP، HTTP یا تأخیر واقعی از داخل hop. **Test all** همه را می‌سنجد؛ انتخاب حالت برای هر دو است.

## سابسکریپشن، WARP، NordVPN، PIA

سابسکریپشن خروجی یک URL است که خروجی می‌دهد؛ طبق زمان‌بندی گرفته می‌شود و ردیف‌هایی که می‌سازد هماهنگ می‌مانند. **WARP** با یک کلیک hop کلادفلر می‌سازد؛ **NordVPN** و **PIA** حساب می‌گیرند و سرور انتخاب می‌کنند.

## بالانسرها

مسیریابی → Balancers خروجی‌ها را گروه می‌کند و از میانشان انتخاب می‌کند: round-robin، کمترین بار، کمترین پینگ، تصادفی، یا بر اساس نتایج observatory، با fallback برای وقتی همه بیفتند و override دستی برای وقتی یکی را مشخصاً می‌خواهی.
