## هر گزینه چه می‌کند

| # | می‌کند | می‌پرسد |
|---|--------|---------|
| 1 | نصاب را اجرا می‌کند | — |
| 2 | آخرین ریلیز را می‌گیرد، امضا را چک می‌کند، باینری و همین اسکریپت را عوض و ریستارت می‌کند — هیچ سؤالی نمی‌پرسد؛ پورت، مسیر، سرتیفیکیت، دیتابیس و مدیر می‌مانند. به پنلی که سرتیفیکیت ندارد یکی پیشنهاد می‌شود | تأیید |
| 3 | همان، از بیلد چرخشی `dev-latest` آخرین کامیت | تأیید |

| 7 | نام کاربری و رمز جدید (تولیدشده مگر بنویسی)، و اینکه ورود دومرحله‌ای حذف شود یا نه | هر دو، 2FA، بعد ریستارت |
| 8 | مسیر URL رندوم جدید | تأیید |

## زیردستورها

```
w-ui start | stop | restart | restart-tunnels | status
w-ui settings                 # پنل واقعاً با چه چیزی اجرا می‌شود
w-ui enable | disable
w-ui log | banlog
w-ui update | update-dev | legacy
w-ui update-all-geofiles
w-ui backup
w-ui install | uninstall
w-ui setup-fail2ban
```

سؤالی که اسکریپت بپرسد و کسی نباشد جواب بدهد — ورودی pipe شده، یک اسکریپت — **نه** حساب می‌شود. اجرای غیرتعاملی هرگز نمی‌تواند چیزی را نصب، به‌روز یا حذف کند.
