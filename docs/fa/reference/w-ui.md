# منوی `w-ui`

کنار پنل نصب می‌شود. `w-ui` منو را باز می‌کند، `w-ui <subcommand>` یک کار را انجام می‌دهد. منو همان `x-ui` سنایی است، شماره به شماره؛ آنچه آن‌جا Xray است این‌جا تانل‌هاست.

## هر گزینه چه می‌کند

| # | می‌کند | می‌پرسد |
|---|--------|---------|
| 1 | نصاب را اجرا می‌کند | — |
| 2 | آخرین ریلیز را می‌گیرد، باینری را عوض و ریستارت می‌کند | تأیید |
| 3 | آخرین کامیت `main` را می‌سازد و نصب می‌کند | تأیید |
| 4 | همین اسکریپت را با نسخهٔ منتشرشده برای نسخهٔ نصب‌شده عوض می‌کند | تأیید |
| 5 | یک نسخهٔ قدیمی‌تر مشخص را نصب می‌کند | نسخه |
| 6 | پنل، داده و unit را حذف می‌کند — **بعد از کپی داده‌ها به `/root/wui-last-copy-…`** | تأیید، پیش‌فرض نه |
| 7 | نام کاربری و رمز جدید (تولیدشده مگر بنویسی) | هر دو، بعد ریستارت |
| 8 | مسیر URL رندوم جدید | تأیید |
| 9 | همهٔ تنظیمات پنل به مقادیر env؛ مدیر و مشتری‌ها می‌مانند | تأیید، پیش‌فرض نه |
| 10 | پورت، در ریستارت بعدی | پورت |
| 11 | listen، پورت، مسیر، سرتیفیکیت، دیتابیس، **Access URL** — و پیشنهاد گرفتن سرتیفیکیت آی‌پی اگر نباشد | — |
| 12–14 | start / stop / restart سرویس | — |
| 15 | همهٔ تانل‌ها دوباره از پیکربندی؛ پنل بالا می‌ماند | — |
| 16 | `systemctl status wui` | — |
| 17 | دنبال کردن لاگ debug، یا پاک کردن همهٔ لاگ‌های journal | کدام |
| 18–19 | فعال / غیرفعال کردن در بوت | — |
| 20 | سرتیفیکیت برای دامنه یا آی‌پی، باطل کردن، تمدید اجباری، لیست، مسیر دلخواه | [سرتیفیکیت](/fa/guide/certificates) |
| 21 | wildcard از طریق DNS API کلادفلر | دامنه، توکن |
| 22 | fail2ban روی فرم ورود: نصب، مدت بن، آزاد کردن همه، لاگ بن، بن / آزاد کردن یکی، لاگ زنده، وضعیت، ریستارت، حذف | کدام |
| 23 | ufw: نصب، لیست، باز کردن، حذف، فعال، غیرفعال، وضعیت | کدام |
| 24 | bind پنل به 127.0.0.1 و چاپ دستور `ssh -L` برای رسیدن به آن | کدام |
| 25 | ساختن، برگرداندن یا لیست بک‌آپ‌ها | کدام |
| 26 | فعال / غیرفعال کردن BBR | کدام |
| 27 | تازه کردن لیست‌های کشور که قوانین مسیریابی استفاده می‌کنند، یا گرفتن یکی | کدام |
| 28 | نصب و اجرای speedtest اوکلا | — |

## زیردستورها

```
w-ui start | stop | restart | restart-tunnels | status
w-ui settings                 # پنل واقعاً با چه چیزی اجرا می‌شود
w-ui enable | disable
w-ui log | banlog
w-ui update | update-dev | legacy
w-ui update-all-geofiles
w-ui backup
w-ui install | uninstall
w-ui setup-fail2ban
```

سؤالی که اسکریپت بپرسد و کسی نباشد جواب بدهد — ورودی pipe شده، یک اسکریپت — **نه** حساب می‌شود. اجرای غیرتعاملی هرگز نمی‌تواند چیزی را نصب، به‌روز یا حذف کند.
