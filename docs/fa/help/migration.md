# از سنایی یا مرزبان آمده‌اید

صفحه‌ها همان‌جا هستند. واژه‌ها این‌طور نگاشت می‌شوند:

| سنایی | مرزبان | W-UI |
|-------|--------|------|
| Inbound | Inbound (کانفیگ Xray) | **اینترفیس** — یک تانل WireGuard / AmneziaWG / OpenVPN |
| Client (email) | User | **Client** — یک مشتری، با یک **account** به ازای هر دستگاه |
| `id` / رمز کلاینت | proxyهای کاربر | کلید دستگاه (وایرگارد) یا نام کاربری + رمز (OpenVPN) |
| Total GB، Expiry، IP limit | Data limit، Expire، — | Total traffic، Expiry، **Device limit** |
| Subscription URL | Subscription URL | لینک سابسکریپشن — همان ایده، با صفحهٔ مشتری |
| Hosts | Host settings | هاست‌ها و گروه‌های هاست |
| Outbounds / Routing / Balancers | Core settings | خروجی‌ها / مسیریابی / بالانسرها — همان تب‌ها |
| Xray settings | Core settings | موتور (basics، balancers، DNS، advanced) |
| منوی `x-ui` | CLI `marzban` | منوی `w-ui`، با همان شماره‌های `x-ui` |
| Restart Xray | Restart core | Restart tunnels |
| Nodes (multi-node) | Marzban-node | نودها — پنل‌های W-UI دیگر که با API پاییده می‌شوند |
| ربات تلگرام | ربات تلگرام | ربات تلگرام |

## چه چیزی معادل ندارد

- **REALITY، VLESS، Trojan، Shadowsocks** — این‌جا نیست؛ این پنل WireGuard و OpenVPN اجرا می‌کند. جایی که آن پروتکل‌ها برای DPI لازم بودند، AmneziaWG گزینهٔ مبهم‌شده است.
- **چند مدیر** — هر پنل یک مدیر.

## چه چیزی برایت تازه است

- **اعمال محدودیت در کرنل** — اضافه‌مصرف سهمیه یک بسته است، نه یک بازهٔ poll.
- **خروجی پیش‌فرض fail-closed** — وقتی hop‌ای که همه چیز از آن خارج می‌شود پایین است، ترافیک دور ریخته می‌شود نه اینکه از آدرس خودِ سرور نشت کند.
- **سرتیفیکیت برای آی‌پی** — HTTPS بدون دامنه، از دقیقهٔ اول.

## انتقال مشتری‌ها

واردکننده‌ای برای دیتابیس سنایی یا مرزبان نیست: اعتبارها جنس متفاوتی دارند (UUID Xray در برابر کلید وایرگارد). مشتری‌ها را این‌جا بساز — ساخت دسته‌ای یک پیشوند و یک تعداد می‌گیرد — و کانفیگ جدید بده.
