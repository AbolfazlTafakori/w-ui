# آمدن از پنلی دیگر

صفحه‌ها همان‌جایی هستند که انتظار دارید. واژه‌ها این‌طور با هم جور می‌شوند:

| پنل‌های Xray (3x-ui) | پاسارگاد، مرزبان | W-UI |
|-------|---------|------|
| اینباند | اینباند (پیکربندی هسته) | **اینترفیس**: یک تونل، با WireGuard، AmneziaWG، OpenVPN، OpenConnect، IKEv2، L2TP/IPsec یا PPTP |
| کلاینت (ایمیل) | کاربر | **کلاینت**: یک مشتری، با یک **حساب** برای هر دستگاه |
| `id` یا رمز کلاینت | پراکسی‌های کاربر | کلید دستگاه (WireGuard) یا نام کاربری و رمز (پروتکل‌های دیگر) |
| حجم کل، انقضا، محدودیت IP | محدودیت داده، انقضا | حجم، مدت اعتبار، **کاربران** |
| آدرس سابسکریپشن | آدرس سابسکریپشن | لینک اشتراک: همان ایده، با صفحه‌ای برای مشتری |
| هاست‌ها | تنظیمات هاست | میزبان‌ها و گروه‌های میزبان |
| خروجی‌ها، مسیریابی، بالانسرها | تنظیمات هسته | خروجی‌ها، مسیریابی، بالانسرها: همان زبانه‌ها |
| تنظیمات Xray | تنظیمات هسته | موتور: پایه، بالانسرها، DNS، پیشرفته |
| منوی شماره‌دار | خط فرمان | منوی `w-ui`، با همان شماره‌گذاری |
| ری‌استارت Xray | ری‌استارت هسته | ری‌استارت تونل‌ها |
| نودها | نودها | نودها: پنل‌های W-UI، 3x-ui یا پاسارگاد دیگر که از طریق API مدیریت می‌شوند |
| ادمین‌ها | ادمین‌ها | مالک، مدیران پنل و [نمایندگان](/fa/panel/operators) |
| ربات تلگرام | ربات تلگرام | ربات تلگرام |

## چه چیزی فرق دارد

- **پروتکل‌ها.** W-UI خودش تونل VPN اجرا می‌کند، نه Xray. برای VLESS، VMess، Trojan، Shadowsocks یا REALITY، پنل Xray خود را نگه دارید و آن را به‌عنوان [نود](/fa/panel/nodes) اضافه کنید: اینباندهایش این‌جا ظاهر می‌شوند و یک لینک اشتراک هر دو را دارد. جایی که VPN ساده فیلتر است، AmneziaWG، OpenConnect روی 443 و OpenVPN روی TCP 443 گزینه‌هایی‌اند که همین‌جا اجرا می‌شوند.
- **اعمال محدودیت در کرنل.** سقف حجم فقط به اندازه‌ی یک بسته رد می‌شود، نه به اندازه‌ی فاصله‌ی بین دو بار خواندن شمارنده.
- **خروجی پیش‌فرضی که با خطا بسته می‌شود.** وقتی هاپی که همه‌ی ترافیک از آن بیرون می‌رود از کار بیفتد، ترافیک قطع می‌شود، نه اینکه از آدرس خود سرور نشت کند.
- **گواهی برای آدرس IP.** HTTPS بدون دامنه، از همان دقیقه‌ی اول.

## آوردن مشتری‌ها

**از یک پنل 3x-ui یا پاسارگاد:** آن را به‌عنوان نود اضافه کنید و بعد روی ردیفش **وارد کردن کاربران** را بزنید. کاربرها اطلاعات ورود، لینک‌ها و اشتراکشان را نگه می‌دارند و برایشان چیزی عوض نمی‌شود. از آن به بعد حجم، مصرف و انقضای آنها این‌جا مدیریت می‌شود و می‌توانید تونل‌های W-UI را هم به آنها بدهید. [وارد کردن کاربرهای خود پنل](/fa/panel/nodes#وارد-کردن-کاربرهای-خود-پنل) را ببینید.

**از هر پنل دیگر:** ابزاری برای وارد کردن دیتابیس پنل‌های دیگر وجود ندارد، چون اطلاعات ورود از جنس‌های متفاوتی‌اند. مشتری‌ها را این‌جا بسازید، که ساخت گروهی با یک پیشوند و یک تعداد انجام می‌شود، و لینک اشتراک تازه‌شان را به آنها بدهید.

**از یک W-UI دیگر:** [بکاپ](/fa/operations/backup-restore) همه چیز را با کلیدها منتقل می‌کند، و **ورود کلاینت‌ها** فهرست مشتری‌ها را با کلیدهای تازه منتقل می‌کند.
