# گواهی برای دامنه

**۱.** یک رکورد `A` برای `panel.example.com` بسازید که به سرور اشاره کند، و صبر کنید تا `dig +short panel.example.com` آدرس سرور را برگرداند.

**۲.** پورت 80 باید به سرور برسد؛ از فایروال ارائه‌دهنده‌ی سرور هم.

**۳.** موقع نصب، گزینه‌ی **1** را انتخاب کنید و نام را بدهید. یا بعداً:

```bash
w-ui          # → 20 → 1 → دامنه
```

منو گواهی را با acme.sh و روش HTTP-01 صادر می‌کند، در `/etc/wui/certs/panel.example.com/` نصب می‌کند، به پنل می‌دهد و پنل را ری‌استارت می‌کند. تمدید خودکار است.

**۴.** بررسی کنید:

```bash
curl -sI https://panel.example.com:41234/ | head -1
w-ui settings | grep -E 'cert|Access'
```

آدرس IP هنوز به همان پورت می‌رسد، فقط با هشدار گواهی. برای اینکه هر دو پوشش داده شوند، [گواهی wildcard از طریق کلادفلر](/fa/examples/wildcard-cloudflare) را ببینید، یا برای IP هم گواهی بگیرید.
