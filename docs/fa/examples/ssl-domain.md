# سرتیفیکیت برای دامنه

**۱.** یک رکورد `A` برای `panel.example.com` به سمت سرور اضافه کن و صبر کن تا `dig +short panel.example.com` آن را برگرداند.

**۲.** پورت 80 باید به سرور برسد (فایروال ارائه‌دهنده هم).

**۳.** موقع نصب گزینهٔ **1** و نام را بده. یا بعداً:

```bash
w-ui          # → 20 → 1 → دامنه
```

منو با acme.sh روی HTTP-01 صادرش می‌کند، زیر `/etc/wui/certs/panel.example.com/` نصب می‌کند، به پنل می‌دهد و ریستارت می‌کند. تمدید خودکار است.

**۴.** بررسی:

```bash
curl -sI https://panel.example.com:41234/ | head -1
w-ui settings | grep -E 'cert|Access'
```

آی‌پی هنوز به همان پورت می‌رسد، فقط با هشدار سرتیفیکیت — برای هر دو، [wildcard از طریق کلادفلر](/fa/examples/wildcard-cloudflare) را ببین یا برای آی‌پی هم صادر کن.
