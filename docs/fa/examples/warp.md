# خروجی Cloudflare WARP

**خروجی‌ها ← بیشتر ← WARP ← ایجاد حساب WARP**، بعد **افزودن خروجی**. پنل یک دستگاه WARP نزد Cloudflare ثبت می‌کند و از آن یک خروجی WireGuard می‌سازد. با **HTTP** **چک کردن**ش کنید: کشورِ آی‌پی خروجی مال Cloudflare می‌شود. **تغییر IP** از Cloudflare آدرس دیگری می‌خواهد؛ کلید WARP+ در **کلید لایسنس WARP / WARP+** می‌رود.

یا پیش‌فرضش کنید (منوی ردیف ← **انتقال به بالا**)، یا فقط برای بعضی مقصدها: **مسیریابی ← قوانین مسیریابی ← افزودن قانون**، در **دامنه** نام‌هایی که لازم دارید، **تگ خروجی** همان خروجی WARP. بقیه مسیر خودشان را می‌روند.

نسخه‌ی رایگان WARP برای یک نفر است نه یک سرور؛ برای استفاده‌ی سنگین، یک هاپ پولی از خودتان.
