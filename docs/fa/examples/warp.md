# خروجی WARP کلادفلر

به **خروجی‌ها ← بیشتر ← WARP ← ایجاد حساب WARP** بروید و بعد **افزودن خروجی** را بزنید. پنل یک دستگاه WARP در Cloudflare ثبت می‌کند و از آن یک خروجی WireGuard می‌سازد. آن را با روش **HTTP** **چک کردن** کنید: کشور آی‌پی خروجی، کشور Cloudflare می‌شود. **تغییر IP** آدرس دیگری از Cloudflare می‌خواهد. کلید WARP+ را در **کلید لایسنس WARP / WARP+** وارد کنید.

می‌توانید آن را پیش‌فرض کنید (منوی ردیف ← **انتقال به بالا**)، یا فقط برای بعضی مقصدها به کار ببرید: **مسیریابی ← قوانین مسیریابی ← قانون جدید**، با **دامنه** روی نام‌هایی که لازم دارید و **تگ خروجی** روی خروجی WARP. بقیه‌ی ترافیک از همان مسیر قبلی می‌رود.

نسخه‌ی رایگان WARP برای استفاده‌ی یک نفر ساخته شده، نه یک سرور. برای استفاده‌ی سنگین، یک هاپ پولی از خودتان راه بیندازید.
