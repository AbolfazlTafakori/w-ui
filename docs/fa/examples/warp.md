# خروجی WARP کلادفلر

**خروجی‌ها → more → WARP.** پنل یک هویت WARP در کلادفلر ثبت می‌کند، از آن یک خروجی وایرگارد می‌سازد و به لیست اضافه می‌کند. Check کن: کشور خروجی کشور کلادفلر می‌شود.

به‌عنوان پیش‌فرض استفاده کن (به بالا ببر) یا فقط برای بعضی مقصدها:

مسیریابی → Rules → **+ Rule**: مقصد دامنه‌هایی که لازم داری (هر خط یکی)، خروجی `warp`. بقیه مسیر خودشان را نگه می‌دارند.

طبقهٔ رایگان WARP برای یک نفر است نه یک سرور؛ برای استفادهٔ سنگین، یک hop پولی خودت.
