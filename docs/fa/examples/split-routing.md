# ترافیک داخلی مستقیم، بقیه از هاپ

وقتی یک هاپ بالای خروجی‌هاست ([همه‌ی ترافیک از یک سرور تمیز](/fa/examples/hop-all-traffic))، سایت‌های داخلی هم این مسیر را می‌روند — کندتر، و گاهی آدرس خارجی را رد می‌کنند.

**مسیریابی ← قوانین مسیریابی ← افزودن قانون:**

| فیلد | مقدار |
|------|-------|
| IP | `geoip:ir` (کشور شما) |
| تگ خروجی | `direct` |

ذخیره کنید. بعد **مسیریابی ← آزمایش مسیر**: یک آدرس داخلی و یک آدرس خارجی بدهید؛ اولی باید `direct` بگوید و دومی هاپ را.

برای دامنه به جای آدرس — بانکی داخلی که آدرس‌هایش جابه‌جا می‌شوند — نام‌ها را در **دامنه**‌ی قانون بنویسید؛ پنل پیدایشان می‌کند و تازه نگهشان می‌دارد.

ترتیب مهم است: قانون‌ها از بالا به پایین امتحان می‌شوند و اولین قانونِ جور تصمیم می‌گیرد. قانون را بالای هر قانونی بکشید که ممکن است همان ترافیک را زودتر بگیرد.
