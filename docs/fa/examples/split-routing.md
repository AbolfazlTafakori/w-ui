# ترافیک داخلی مستقیم، بقیه از hop

با یک hop بالای خروجی‌ها ([همهٔ ترافیک از یک سرور تمیز](/fa/examples/hop-all-traffic))، سایت‌های داخلی هم دور می‌زنند — کندتر، و گاهی آدرس خارجی را رد می‌کنند.

**مسیریابی → Rules → + Rule:**

| فیلد | مقدار |
|------|-------|
| Destination | `geoip:ir` (کشور خودت) |
| Outbound | `direct` |

ذخیره. مسیریابی → **Route tester**: یک آدرس داخلی و یک خارجی بده؛ اولی باید `direct` بگوید، دومی hop.

برای دامنه به جای آدرس — یک بانک داخلی که آدرس‌هایش جابه‌جا می‌شود — خودِ نام‌ها را در مقصد بگذار؛ پنل آن‌ها را از DNS proxy خودش resolve می‌کند و مجموعه‌ها را تازه نگه می‌دارد.

ترتیب مهم است: قوانین از بالا به پایین امتحان می‌شوند و اولین تطبیق برنده است.
