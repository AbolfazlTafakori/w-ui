# گواهی برای آی‌پی، بدون دامنه

سرویس Let's Encrypt برای آدرس IP با پروفایل *short-lived* گواهی صادر می‌کند: حدود شش روز اعتبار دارد و برای تمدید خودکار ساخته شده.

**موقع نصب** همین گزینه پیش‌فرض است؛ در سؤال گواهی فقط Enter بزنید.

**بعداً:**

```bash
w-ui          # → 20 → 6
```

آدرسی را که تشخیص داده شده تأیید کنید، اگر خواستید یک IPv6 هم اضافه کنید، و پورتی برای شنونده‌ی HTTP-01 بدهید: 80، مگر اینکه برنامه‌ی دیگری آن را گرفته باشد؛ در آن صورت پورت 80 بیرونی را به پورتی که می‌دهید فوروارد کنید.

**تمدید:** `wui-cert-renew.timer` هر شش ساعت acme.sh را اجرا می‌کند و acme.sh وقتی گواهی شش روزه شد تمدیدش می‌کند. پنل با تغییر فایل‌ها دوباره آنها را می‌خواند. بررسی کنید:

```bash
systemctl list-timers wui-cert-renew.timer
openssl s_client -connect 203.0.113.9:41234 </dev/null 2>/dev/null | openssl x509 -noout -dates
```

::: tip
پورت 80 باید در دسترس بماند، چون هر تمدید روی آن به یک چالش جواب می‌دهد.
:::
