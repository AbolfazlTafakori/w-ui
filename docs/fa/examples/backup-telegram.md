# بک‌آپ به تلگرام

**۱.** تنظیمات → تلگرام: فعال، توکن ربات، شناسهٔ چت. ذخیره؛ ربات تا پانزده ثانیه سلام می‌کند.

**۲.** تنظیمات → General → Backups: زمان‌بندی (روزانه برای بیشتر افراد درست است)، چند تا نگه داشته شود، و **send to Telegram**. ذخیره.

**۳.** نمای کلی → Backup → *Back up now* برای تست؛ فایل به چت می‌رسد.

آرشیو دیتابیس، کلیدها و اعتبار همهٔ مشتری‌ها را دارد — چت باید فقط مال تو باشد. از هر کدام برگردان: نمای کلی → Backup → Restore، یا `w-ui` → 25.
