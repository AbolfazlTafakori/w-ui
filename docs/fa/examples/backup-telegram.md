# بکاپ به تلگرام

**۱.** *تنظیمات ← ربات تلگرام ← پیکربندی*: **فعال‌سازی ربات تلگرام** را روشن کنید، توکن ربات را بچسبانید، شناسه‌ی چت خودتان را در **آی‌دی چت مدیر** بگذارید. ذخیره؛ ربات ظرف پانزده ثانیه شروع می‌شود — برای اطمینان **ارسال پیام آزمایشی**.

**۲.** *تنظیمات ← ربات تلگرام ← بکاپ*: **بکاپ خودکار** را روشن کنید و **زمان ارسال** را انتخاب کنید — برای بیشتر افراد روزانه در ساعتی خلوت درست است. ذخیره.

**۳.** برای امتحان همین الان، در منوی ربات **💾 پشتیبان دیتابیس** را بزنید: آرشیو به چت می‌رسد.

آرشیو دیتابیس، کلیدها و اطلاعات ورود همه‌ی مشتری‌ها را دارد — چت باید فقط مال خودتان باشد. از هر کدام بازگردانی کنید: نمای کلی ← **بکاپ و بازگردانی** ← *انتخاب فایل*، یا روی سرور `w-ui` ← ۲۵ ← ۹ ← ۲. بیشتر در [ربات تلگرام](/fa/panel/telegram#بکاپ-خودکار).
