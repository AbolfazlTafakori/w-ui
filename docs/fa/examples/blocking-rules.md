# مسدود کردن تبلیغ و بیت‌تورنت

**مسیریابی → Basic.**

- **Block BitTorrent** پیش‌فرض روشن است — پورت‌های معروف در `wui_block` drop می‌شوند، قبل از هر شمارشی، پس چیزی که drop شد به حساب کسی نمی‌رود.
- **Blocked addresses** پیش‌فرض `geoip:private` دارد، پس مشتری‌ها به LAN تو نمی‌رسند.
- به **Blocked domains** اضافه کن: نام‌هایی که باید drop شوند، هر خط یکی (دامنه‌های یک لیست تبلیغ مستقیم می‌چسبند). نام‌ها resolve و تازه می‌شوند؛ آدرس‌ها به مجموعه‌های `blocked4` / `blocked6` می‌روند.
- به **Blocked addresses** اضافه کن: یک CIDR، یک آدرس، `geoip:xx` برای یک کشور.

ذخیره؛ ruleset فوراً اعمال می‌شود. بررسی:

```bash
nft list chain inet wui_policy wui_block
```

برای مسدود کردن فقط برای یک مشتری یا یک گروه، به جایش قانون بگذار: مسیریابی → Rules → منبع *گروه*، مقصد *دامنه‌ها*، خروجی **blocked**.
