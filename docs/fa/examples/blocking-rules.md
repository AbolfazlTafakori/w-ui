# مسدود کردن تبلیغات و بیت‌تورنت

به **مسیریابی ← مسیریابی پایه** بروید.

- **مسدودسازی پروتکل بیت‌تورنت** پیش‌فرض روشن است. پورت‌هایی که برنامه‌های بیت‌تورنت به‌طور پیش‌فرض استفاده می‌کنند، در کرنل و پیش از هر شمارشی دور ریخته می‌شوند؛ پس ترافیک دورریخته از حجم کسی کم نمی‌شود. برنامه‌ای که پورتش را عوض کرده باشد گرفته نمی‌شود.
- **مسدود کردن آی‌پی‌ها** به‌طور پیش‌فرض `geoip:private` را دارد، تا مشتری‌ها به شبکه‌ی محلی شما یا شبکه‌های خصوصی خود سرور نرسند.
- نام‌هایی را که باید بسته شوند به **مسدود کردن دامنه‌ها** اضافه کنید؛ دامنه‌های یک فهرست تبلیغات را می‌شود مستقیم چسباند. پنل آنها را ترجمه می‌کند و هر ۱۵ دقیقه به‌روز می‌کند. آنچه بسته می‌شود آدرس‌هاست، پس هر نامی را که منظورتان است بنویسید (هم `www.example.com` و هم `example.com`).
- به **مسدود کردن آی‌پی‌ها** یک آدرس، یک بازه، یا `geoip:xx` برای یک کشور کامل اضافه کنید.
- **مسدود کردن پورت‌ها** یک پورت را برای همه می‌بندد؛ بستن `25` جلوی این را می‌گیرد که اسپم مشتری‌ها به نام آدرس شما گزارش شود.

**ذخیره** را بزنید؛ تغییر همان لحظه اعمال می‌شود. با این دستور ببینید کرنل چه چیزی را نگه داشته:

```bash
nft list chain inet wui_policy wui_block
```

برای مسدود کردن فقط برای یک مشتری یا یک گروه، به جای این‌ها یک قانون بسازید: **مسیریابی ← قوانین مسیریابی ← قانون جدید**، با **کاربر** یا **گروه** روی کسانی که باید مسدود شوند، **دامنه** یا **IP** روی مقصدها، و **تگ خروجی** روی `blocked`. [مسیریابی](/fa/panel/routing) را ببینید.
