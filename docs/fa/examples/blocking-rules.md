# مسدود کردن تبلیغات و بیت‌تورنت

**مسیریابی ← مسیریابی پایه.**

- **مسدودسازی پروتکل بیت‌تورنت** پیش‌فرض روشن است — پورت‌هایی که برنامه‌های بیت‌تورنت به طور پیش‌فرض استفاده می‌کنند در کرنل، پیش از هر شمارشی، دور ریخته می‌شوند، پس چیزی که دور ریخته شده حساب نمی‌شود. برنامه‌ای که از این پورت‌ها جابه‌جا شده گرفته نمی‌شود.
- **مسدود کردن آی‌پی‌ها** پیش‌فرض `geoip:private` را دارد، تا مشتری‌ها به شبکه‌ی محلی شما یا شبکه‌های خصوصی خود سرور نرسند.
- نام‌هایی را که باید بسته شوند به **مسدود کردن دامنه‌ها** اضافه کنید — دامنه‌های یک فهرست تبلیغات را می‌شود مستقیم چسباند. پنل آنها را پیدا و هر ۱۵ دقیقه تازه می‌کند؛ آدرس‌ها هستند که بسته می‌شوند، پس هر نامی را که منظورتان است بنویسید (`www.example.com` و `example.com` هر دو).
- به **مسدود کردن آی‌پی‌ها** یک آدرس، یک بازه، یا `geoip:xx` برای یک کشور کامل اضافه کنید.
- **مسدود کردن پورت‌ها** یک پورت را برای همه می‌بندد — `25` جلوی گزارش شدن اسپم مشتری‌ها به نام آدرس شما را می‌گیرد.

**ذخیره**؛ همان لحظه اعمال می‌شود. آنچه کرنل نگه داشته را با این ببینید:

```bash
nft list chain inet wui_policy wui_block
```

برای مسدود کردن فقط برای یک مشتری یا یک گروه، به جایش یک قانون بگذارید: **مسیریابی ← قوانین مسیریابی ← افزودن قانون** — در **کاربر** یا **گروه** همان‌ها، در **دامنه** یا **IP** مقصدها، و **تگ خروجی** `blocked`. [مسیریابی](/fa/panel/routing) را ببینید.
