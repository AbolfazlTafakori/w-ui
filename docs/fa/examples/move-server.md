# انتقال پنل به سرور دیگر

چون کلیدها و پورت‌های اینترفیس‌ها در دیتابیس‌اند، پنل برگردانده‌شده برای هر مشتری همان پنل است.

**۱. سرور قدیمی** — بک‌آپ بگیر: نمای کلی → Backup → *Back up now*، یا `w-ui` → 25 → 1. بیرون ببر.

**۲. سرور جدید** — با همان پورت و مسیر نصب کن (`--port` / `--path`)، بعد:

```bash
systemctl stop wui
tar xzf wui-backup-….tar.gz -C /
chown -R wui:wui /var/lib/wui
systemctl start wui
```

**۳. آدرس‌ها** — اگر کانفیگ مشتری‌ها دامنه دارد، رکورد DNS را جابه‌جا کن. اگر آی‌پی قدیمی را دارد، *Endpoint host* هر اینترفیس (و هر هاست در هاست‌ها) را به آدرس جدید ویرایش کن؛ مشتری‌ها از لینک سابسکریپشن دوباره می‌گیرند.

**۴. سرتیفیکیت** — اگر قدیمی برای دامنه بود، روی سرور جدید دوباره `w-ui` → 20 → 1؛ برای آی‌پی → 6.

سرور قدیمی می‌تواند در طول جابه‌جایی روشن بماند — هر دو همان محدودیت‌ها را از همان داده اعمال می‌کنند، و مشتری روی هر کدام همان‌جا شمرده می‌شود.
