# گواهی wildcard از طریق کلادفلر

**۱.** در کلادفلر به *My Profile → API Tokens → Create Token → Edit zone DNS* بروید و توکن را فقط به همان یک zone محدود کنید. توکن را کپی کنید.

**۲.** این را اجرا کنید:

```bash
w-ui          # → 21
```

دامنه (`example.com`) را بدهید، **t** را برای توکن انتخاب کنید و توکن را بچسبانید. acme.sh از Let's Encrypt گواهی `example.com` و `*.example.com` را با روش DNS-01 می‌گیرد، که به پورت 80 نیازی ندارد؛ جفت گواهی و کلید را در `/etc/wui/certs/example.com/` نصب می‌کند و پیشنهاد می‌دهد آن را برای پنل تنظیم کند.

**۳.** حالا هر نامی زیر این zone برای پنل، سرویس سابسکریپشن، یا یک میزبان در صفحه‌ی میزبان‌ها کار می‌کند.
