# به‌روزرسانی و حذف

## به‌روزرسانی

```bash
w-ui update
```

یا `w-ui` → **2. Update**. آخرین ریلیز را می‌گیرد، چک‌سام و امضایش را بررسی می‌کند، باینری و اسکریپت `w-ui` را عوض می‌کند و پنل را ریستارت می‌کند. **هیچ سؤالی نمی‌پرسد**: پورت، مسیر URL، سرتیفیکیت، دیتابیس و مدیر همان‌هایی‌اند که نصب دارد. تنها استثنا پنلی است که اصلاً سرتیفیکیت ندارد، که یکی به آن پیشنهاد می‌شود. تنظیمات، مشتری‌ها و کلیدها می‌مانند. مشتری‌های وایرگارد وصل می‌مانند: تانل‌ها شیء کرنل‌اند و پنل فقط اینترفیسی را ریستارت می‌کند که پیکربندی‌اش واقعاً عوض شده باشد.

`w-ui update-dev` (منو ۳) بیلد چرخشی `dev-latest` آخرین کامیت را نصب می‌کند — برای امتحان یک fix قبل از ریلیز.

همین کار بدون منو، روی هر ماشینی:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/AbolfazlTafakori/w-ui/main/update.sh)
```

`w-ui legacy` (منو ۵) یک نسخهٔ قدیمی‌تر مشخص را نصب می‌کند.

هر ریلیز امضا شده است. پنلی که با کلید عمومی پروژه ساخته شده، به‌روزرسانی‌ای را که امضایش نخواند رد می‌کند؛ صفحهٔ ریلیز `SHA256SUMS` هم دارد.

## حذف

```bash
w-ui uninstall
```

یا `w-ui` → **6. Uninstall**. قبل از حذف هر چیزی، یک کپی از دیتابیس و همهٔ کلیدها در `/root/wui-last-copy-<date>.tar.gz` (mode 600) نوشته می‌شود — حذف اشتباهی روی سرور اشتباهی یک خطاست، نه فاجعه.

WireGuard، OpenVPN و nftables نصب می‌مانند؛ چیزهای دیگری روی سرور ممکن است از آن‌ها استفاده کنند. تانل‌هایی که بالا بودند تا ریبوت بعدی بالا می‌مانند.

## بک‌آپ

پنل خودش طبق زمان‌بندی (تنظیمات → عمومی) در `/var/backups/wui` بک‌آپ می‌گیرد، تعدادی را نگه می‌دارد، و می‌تواند هر کدام را به تلگرام بفرستد. `w-ui` → **25. Backup & Restore** از شل می‌سازد یا برمی‌گرداند. آرشیو یک snapshot سازگار است — دیتابیس را خودِ SQLite کپی می‌کند، نه اینکه فایلی که در حال نوشتن است خوانده شود.
