# اولین ورود

بعد از نصب، اولین کار ورود به پنل و **امن کردن آن** است؛ پیش از اینکه مشتری‌ای رویش بگذارید.

## رسیدن به پنل

```text
https://<address-or-domain>:<port>/<path>/
```

نصاب پورت، مسیر و اطلاعات ورود را چاپ می‌کند و در فایلی می‌نویسد که فقط root می‌تواند بخواند:

```bash [/etc/wui/install-result.env  (mode 600)]
WUI_USERNAME=…
WUI_PASSWORD=…
WUI_PANEL_PORT=…
WUI_WEB_BASE_PATH=…
WUI_ACCESS_URL=…
WUI_API_TOKEN=…
WUI_DB_TYPE=sqlite
```

اگر آن‌ها را ندیدید، هر کدام از این دو دوباره نشانشان می‌دهد:

```bash
w-ui              # menu → 11 (Show current settings)
w-ui settings     # the same, without the menu
```

::: warning
نام کاربری و رمز پیش‌فرض `admin` / `admin` وجود ندارد، چون هر دو ساخته می‌شوند. اگر برای راحتی `--username admin --password …` را به نصاب داده‌اید، همین حالا و پیش از اولین مشتری عوضشان کنید.
:::

## عوض کردن پورت و مسیر

پورتی غیر از پورت‌های رایج و یک **مسیر** طولانی و تصادفی، پنل را از فهرست اسکنرها دور نگه می‌دارد. هر دو از ابتدا تصادفی‌اند. برای تغییرشان بعداً:

- گزینهٔ **`w-ui` ← 8، Reset the URL path**، مسیر تصادفی تازه‌ای می‌سازد.
- گزینهٔ **`w-ui` ← 10، Change the port**.
- یا در پنل، *تنظیمات ← پیکربندی ← پیکربندی*: **پورت** و **مسیر URI**.

هر دو در ری‌استارت بعدی اعمال می‌شوند؛ پس اول آدرس تازه را یادداشت کنید.

## عوض کردن مدیر پنل

- گزینهٔ **`w-ui` ← 7، Reset username and password**، هر دو را می‌سازد، مگر اینکه خودتان وارد کنید.
- یا در پنل، *تنظیمات ← احرازهویت ← اعتبارنامه‌های ادمین*.

با عوض شدن رمز، همهٔ نشست‌ها بسته می‌شوند.

## ورود دومرحله‌ای

در *تنظیمات ← احرازهویت ← احراز هویت دو مرحله‌ای*، دکمهٔ **فعال‌سازی 2FA** را بزنید. کد را با یک برنامهٔ TOTP، مثل Google Authenticator یا Aegis یا 1Password، اسکن کنید و یک کد را تأیید کنید. از آن به بعد صفحهٔ ورود یک کد شش‌رقمی می‌خواهد، **آن هم فقط بعد از درست بودن رمز**؛ پس فرم هیچ‌وقت لو نمی‌دهد ورود دومرحله‌ای روی کدام حساب‌ها روشن است.

خاموش کردنش یک کد یا رمز شما را می‌خواهد. پس اگر گوشی گم شود و رمز را بدانید، پشت در نمی‌مانید. اگر هر دو از دست رفته باشد، `w-ui` ← 7 حساب را از روی سرور بازنشانی می‌کند و ورود دومرحله‌ای را هم خاموش می‌کند.

## محافظت‌های فرم ورود

- **محدودسازی.** پنج تلاش آزاد برای هر آدرس و هر حساب؛ بعد از آن انتظاری که از ۳۰ ثانیه شروع می‌شود و هر بار دو برابر می‌شود، تا سقف ۱۵ دقیقه. سابقه‌ای که مدتی بی‌تلاش بماند فراموش می‌شود.
- **یک پیام خطا.** رمز غلط و کد غلط هر دو یک پیام می‌گیرند: «incorrect username or password».
- **برنامهٔ fail2ban.** نصاب آن را برای پاییدن لاگ خود پنل راه می‌اندازد و کسی که مدام تلاش کند، روی پورت پنل مسدود می‌شود. مدیریتش از `w-ui` ← 22 است.
- **نشست‌ها.** پیش‌فرض دوازده ساعت (*تنظیمات ← پیکربندی ← بیشینه زمان جلسه وب*)، و همه با عوض شدن رمز تمام می‌شوند.
- **مسیر.** هیچ آدرسی بیرون از آن جواب نمی‌دهد، حتی صفحهٔ ورود.
