# اولین تونل، اولین مشتری

پنل تازه عمداً خالی است: بدون اینترفیس، بدون مشتری، با یک مدیر. با سه قدم اولین مشتری وصل می‌شود.

## ۱. ساختن اینترفیس

به **اینترفیس‌ها ← افزودن اینترفیس** بروید. هر اینترفیس یک تونل است: پروتکلی روی یک پورت، که از یک بازه آدرس می‌دهد و مشتری‌ها از راه آدرس عمومی سرور به آن وصل می‌شوند.

| فیلد | توضیح |
|------|-------|
| سرور | همین سرور، یا یکی از نودهای شما. روی نود 3x-ui یا Pasarguard، فرم به‌جای تونل، اینباندهای خود آن پنل را می‌سازد. |
| پروتکل | وایرگارد، OpenVPN، OpenConnect، IKEv2، L2TP/IPsec یا PPTP؛ پروتکل‌هایی پیشنهاد می‌شوند که روی سرور نصب‌اند |
| اینترفیس | نام تونل، که نام دستگاه شبکه هم هست (`wg0`) |
| اندپوینت | نام دامنه یا آدرس IP که در فایل مشتری‌ها نوشته می‌شود |
| پورت | برای وایرگارد UDP. پروتکل OpenVPN می‌تواند TCP باشد و روی 443 از جاهایی رد می‌شود که چیز دیگری رد نمی‌شود |
| ساب‌نت | بازهٔ `10.66.0.0/16` حدود ۶۵٬۰۰۰ آدرس می‌دهد؛ اولین آدرس دروازه می‌شود |
| MTU | مقدار `1420` برای بیشتر شبکه‌ها مناسب است |
| DNS | به مشتری‌ها داده می‌شود، مگر اینکه DNS خود پنل روشن باشد؛ که به‌طور پیش‌فرض روشن است |
| اینترفیس خروجی | کارت شبکهٔ عمومی سرور، معمولاً `eth0` |
| حالت | برای وایرگارد: استاندارد، یا AmneziaWG که وایرگارد مبهم‌شده برای شبکه‌هایی است که وایرگارد ساده را می‌بندند |

کلیدها خودکار ساخته می‌شوند و کلید خصوصی هیچ‌وقت در چیزی که از پنل کپی می‌کنید دیده نمی‌شود. برای OpenVPN یک مرجع صدور سرتیفیکیت، سرتیفیکیت سرور و کلید `tls-crypt` ساخته و همراه اینترفیس ذخیره می‌شود؛ پس بکاپ دیتابیس یک بکاپ کامل است. همهٔ فیلدها و تنظیمات خاص هر پروتکل در [اینترفیس‌ها](/fa/panel/interfaces) آمده‌اند.

## ۲. ساختن مشتری

به **کلاینت‌ها ← افزودن کلاینت‌ها** بروید. هر کلاینت یعنی یک مشتری و پلن او.

| فیلد | توضیح |
|------|-------|
| نام | چیزی که بعداً با آن جست‌وجو می‌کنید؛ فایل‌های مشتری هم به همین نام‌اند |
| حجم | خالی یا `0` یعنی نامحدود. کرنل این سقف را اعمال می‌کند |
| کاربران | پلن برای چند نفر است: برای هر نفر یک فایل، و هر فایل هم‌زمان فقط روی یک دستگاه |
| مدت اعتبار | از همین حالا چقدر. یا **On hold (شروع با اولین اتصال)** را روشن کنید و تعداد روز بدهید تا از اولین اتصال شمرده شود |
| محدودیت سرعت | سرعت دانلود به Mbit/s؛ `0` یعنی بدون سقف |
| تمدید | هرگز، روزانه، هفتگی یا ماهانه: حجم در هر دوره برمی‌گردد |
| شناسهٔ تلگرام | مشتری می‌تواند وضعیت پلن خودش را از ربات بپرسد |
| سرورهایی که این مشتری می‌تواند استفاده کند | اینترفیس‌هایی که مشتری روی آن‌هاست؛ یکی یا چند تا |

دکمه‌های **آماده** یک پلن معمول را با یک کلیک پر می‌کنند. گزینهٔ **بیشتر ← افزودن گروهی** تا ۲۰۰ مشتری را با یک پیشوند نام و یک تعداد، یک‌جا می‌سازد. همهٔ فیلدها در [کلاینت‌ها](/fa/panel/clients) آمده‌اند.

## ۳. تحویل پیکربندی به مشتری

روی ردیف مشتری این‌ها هست:

- **کد QR:** برای هر کاربر، روی هر اینترفیس و هر میزبان یکی. گوشی آن را با برنامهٔ همان تونل، مثل WireGuard یا AmneziaWG، اسکن می‌کند.
- **اطلاعات کلاینت:** همهٔ فایل‌ها و لینک‌ها، برای کپی یا دانلود.
- **لینک اشتراک:** یک آدرس که مشتری نگه می‌دارد. صفحهٔ پشت آن همهٔ فایل‌ها را با کد QR، به زبان مشتری و با قالبی که انتخاب کرده‌اید، فهرست می‌کند. برنامه‌هایی که سابسکریپشن می‌خوانند آن را خودشان دوباره دریافت می‌کنند؛ پس تغییری که بعداً می‌دهید بدون فایل تازه به آن‌ها می‌رسد.

کدام برنامه روی کدام دستگاه: [برنامه‌های کلاینت](/fa/guide/client-apps).

## معنی وضعیت‌ها

| وضعیت | یعنی |
|-------|------|
| **فعال** | کار می‌کند |
| **غیرفعال** | شما خاموشش کرده‌اید |
| **اتمام حجم** | همهٔ حجمش را مصرف کرده است |
| **منقضی** | تاریخ پایانش گذشته است |
| **در انتظار شروع** | منتظر اولین اتصال است تا زمانش شروع شود |

فایل‌های مشتری‌ای که فعال یا در انتظار شروع نیست از کرنل برداشته می‌شوند و ترافیکش متوقف می‌شود. حجم یا زمان بیشتر، بازنشانی یا تمدید، او را فوراً برمی‌گرداند؛ بدون ری‌استارت و بدون فایل تازه.

## تفاوت مشتری‌های OpenVPN

وایرگارد فایل مشتری را با کلیدش می‌شناسد. مشتری‌های OpenVPN به‌جای آن نام کاربری و رمز می‌گیرند و **برای هر مشتری سرتیفیکیت جداگانه‌ای در کار نیست**: ساختن مشتری یک ورود اضافه می‌کند، نه سرتیفیکیتی که باید صادر و بعداً باطل شود. سه نتیجه دارد:

- **هر ورود مال یک نفر است.** اتصال دوم با همان ورود، اولی را قطع می‌کند.
- **آدرس‌ها ثابت می‌مانند،** پس کرنل بعد از هر اتصال دوباره هم برای همان نفر می‌شمارد.
- **قطع کردن فوری است.** ورود حذف می‌شود *و* نشست زنده هم بسته می‌شود.

افزودن یا حذف مشتری هیچ‌وقت سرور را ری‌استارت نمی‌کند، و ری‌استارت یا به‌روزرسانی پنل هیچ‌کس را قطع نمی‌کند.
