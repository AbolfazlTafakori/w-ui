# اولین تانل، اولین مشتری

پنل تازه عمداً خالی است: بدون اینترفیس، بدون مشتری، یک مدیر. سه قدم یک مشتری را وصل می‌کند.

## ۱. یک اینترفیس بساز

**اینترفیس‌ها → Add Inbound.** اینترفیس یک تانل است: یک زیرشبکه، یک پورت، و نام عمومی‌ای که مشتری‌ها به آن وصل می‌شوند.

| فیلد | توضیح |
|------|-------|
| Protocol | `wireguard` یا `openvpn` |
| Mode | `standard`، یا `amnezia` — وایرگارد مبهم‌شده برای شبکه‌هایی که نسخهٔ ساده را می‌بندند |
| Subnet | `10.66.0.0/16` حدود ۶۵ هزار آدرس می‌دهد؛ `.1` گیت‌وی می‌شود |
| Listen port | UDP برای وایرگارد؛ OpenVPN می‌تواند TCP 443 باشد که از جایی رد می‌شود که کم چیزی رد می‌شود |
| Endpoint host | نام یا آی‌پی‌ای که در کانفیگ مشتری می‌رود |
| NAT interface | کارت شبکهٔ عمومی، معمولاً `eth0` — masquerade به آن نیاز دارد |
| MTU | `1420` برای بیشتر شبکه‌ها مناسب است |

جفت‌کلید برایت ساخته می‌شود. کلید خصوصی هرگز در هیچ کانفیگی که از پنل کپی می‌کنی ظاهر نمی‌شود. برای OpenVPN یک CA، سرتیفیکیت سرور و کلید `tls-crypt` داخل خود پنل ساخته و کنار اینترفیس ذخیره می‌شود — بک‌آپ دیتابیس یک بک‌آپ کامل است.

## ۲. یک مشتری بساز

**مشتری‌ها → Add Clients.** هر client یک مشتری است؛ به ازای هر دستگاهِ مجاز یک account با کلید و آدرس خودش می‌گیرد.

| فیلد | توضیح |
|------|-------|
| Name | همان که بعداً جست‌وجو می‌کنی |
| Protocol | برای هر مشتری جدا |
| Interface(s) | مشتری از کدام تانل‌ها می‌تواند استفاده کند |
| Total traffic | `0` = نامحدود؛ در کرنل اعمال می‌شود |
| Expiry | `0` = هرگز؛ یا **شروع از اولین استفاده** با تعداد روز |
| Device limit | چند کانفیگ جدا صادر شود |
| Reset cycle | `none`، `daily`، `weekly`، `monthly` |
| Speed limit | کلاس HTB برای هر مشتری روی هر دستگاهی که ترافیکش از آن خارج می‌شود |
| Telegram id | تا مشتری بتواند از ربات دربارهٔ پلن خودش بپرسد |

**دسته‌ای:** همان فرم چند مشتری را یک‌جا می‌سازد — یک پیشوند و یک تعداد.

## ۳. کانفیگ را بده

ردیف مشتری را باز کن:

- **QR code** — یکی برای هر دستگاه، برای هر هاست؛ اپ WireGuard یا AmneziaWG اسکن می‌کند.
- **Client information** — همهٔ لینک‌ها، همهٔ دانلودها، لینک سابسکریپشن.
- **لینک سابسکریپشن** — یک URL که مشتری نگه می‌دارد؛ صفحهٔ پشت آن همهٔ دستگاه‌ها و هاست‌ها را با QR، به زبان مشتری و با تمپلیت انتخابی تو نشان می‌دهد. اپ‌هایی که سابسکریپشن می‌فهمند دوباره می‌گیرند.

## معنی وضعیت‌ها

| وضعیت | معنی |
|-------|------|
| `active` | کار می‌کند |
| `disabled` | تو خاموشش کرده‌ای |
| `exhausted` | حجم تمام شده |
| `expired` | تاریخ گذشته |

هر چیزی جز `active` peerهایش از کرنل حذف می‌شود و ترافیک مشتری قطع می‌شود. بالا بردن حجم یا تمدید تاریخ همان لحظه برش می‌گرداند — بدون ریستارت، بدون کانفیگ جدید.

## مشتری‌های OpenVPN چه فرقی دارند

وایرگارد مشتری را با کلید می‌شناسد. مشتری OpenVPN نام کاربری و رمز می‌گیرد، و **سرتیفیکیت جداگانه برای هر مشتری وجود ندارد**: ساختن مشتری یعنی اضافه کردن یک credential، نه صدور و باطل کردن یک سرتیفیکیت. سه خاصیت از این می‌آید:

- **یک credential فقط یک نفر را سرویس می‌دهد** — `duplicate-cn` خاموش است؛ ورود دوم اولی را قطع می‌کند؛
- **آدرس‌ها ثابت‌اند** با `client-config-dir`، پس سهمیهٔ nftables در reconnectها همان آدم را می‌شمارد؛
- **قطع کردن فوری است** — credential حذف می‌شود *و* نشست زنده از management socket کشته می‌شود.

اضافه یا حذف کردن مشتری هرگز سرور را ریستارت نمی‌کند، و ریستارت یا ارتقای پنل کسی را قطع نمی‌کند.
